# Oratry coaching policy — version 1.0.0

Coaching consumes a validated evaluation; it never reevaluates the transcript and never calls an LLM in the normal production flow. Return only the recommendation and next-exercise fields already present in the validated evaluation.

There must be exactly one focus: the evaluation's `primary_weakness`. State one observable issue, one behavior the learner can perform on a retry, and one measurable success criterion. Keep the action independent of accent, identity, personality, and assumed emotional state. Do not author a thesis, arguments, examples, or a complete response for the learner. Do not add secondary weaknesses.
